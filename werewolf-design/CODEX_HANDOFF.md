# Codexへの依頼文（そのまま貼り付けOK）

`mockup.html` を実際のゲーム画面に当てはめ、9人村のルールに合わせるための依頼文です。`mockup.html` を Codex のプロジェクトフォルダに置いてから、下の枠内を貼り付けてください。

---

```
次の2点をお願いします。
(1) 配役を下の「9人村ルール」に変更する
(2) 観戦画面の見た目を、同じフォルダにある mockup.html のデザインに合わせる
既存の仕組み（情報分離・秘密投票・同票処理・護衛・勝敗判定）とテストは壊さないでください。
配役の変更に必要なテストは追加してください。

■ 9人村ルール
- 役職カード10枚：人狼2・狂人1・占い師1・霊媒師1・騎士1・村人4（この10枚は公開する）
- 人狼2枚は必ず配る。残り8枚をシャッフルし、7枚を配って1枚を「伏せ札」にする
  （伏せ札になる確率は村人50%、狂人・占い師・霊媒師・騎士がそれぞれ12.5%）
- 伏せ札は決着まで誰にも公開しない。AIプレイヤーへのプロンプト・ゲーム状態・ログのどこにも混ぜない
  観戦用のログにだけ記録し、決着時に表示する
- 夜0：占い師に、ランダムな1人（人狼以外、自分以外）を「人間」として知らせる
- 占い・霊媒の結果：人狼だけが「人狼」、狂人を含むそれ以外は「人間」
- 処刑された人の役職は公開しない（霊媒師だけが翌朝に知る）
- 騎士：自分は守れない。連続で同じ人を守れるかは今の実装のまま
- 勝利条件：人狼が0人で村陣営の勝ち。
  生存している人狼の数が、それ以外の生存者（狂人を含む）の数以上になったら人狼陣営の勝ち
- 進行：夜0 → 昼（議論3周 → 秘密投票 → 開票 → 処刑）→ 夜（占い・霊媒・護衛・襲撃）→ 次の昼 … を決着まで繰り返す

■ 画面構成（mockup.html と同じ）
1. ヘッダー：タイトル「AI人狼」＋「観戦モード · 9人村 · 人狼2 · 伏せ札1枚」、右に操作ボタン
   ［一時停止/再生］［速度 1×→2×→4×］［役職を表示］［最初から］
2. フェーズの進み具合：夜0·お告げ → 1日目·議論 → 1日目·投票 → 夜1·襲撃 → 2日目·議論 … → 決着
   いまのフェーズを塗りつぶしで強調（夜は紺色）。日数に合わせて項目を増やす
3. 左上：参加者カード（3列）。アバター（名前の頭文字＋参加者ごとの色）と名前
   - 発言中のカード：枠をその参加者の色にして少し浮かせる
   - バッジ：「占い師CO」「霊媒師CO」「投票済 ✓」「処刑」「襲撃」
   - 役職バッジは「役職を表示」がONのときだけ出す（村陣営は緑、人狼陣営は赤）
   - 処刑・襲撃されたらグレーにする。開票時は右上に得票数を出す（翌日になったら消す）
4. 左下：役職カード一覧。10枚を並べ、伏せ札の1枚は点線の「伏せ札 ？」にしておき、決着時に中身を表示する
5. 右：広場（チャット形式）
   - 日が変わるごとに「2日目」の見出し、周回ごとに「議論 2周目」の区切り線
   - 発言はアバター＋吹き出し
   - 占い・霊媒の結果は色付きのチップ：人狼＝赤「● 人狼」、人間＝緑「○ 人間」
   - システム通知（夜明け・投票開始・処刑・襲撃）は中央寄せの小さいピル
   - 開票は得票数の横棒グラフと「誰→誰」の一覧
   - 新しい発言が来たら自動で下までスクロール
6. 決着：画面中央に勝敗カード（勝った陣営・「伏せ札は ○○ でした」・日数・発言数・全員の役職公開）
   ［ログを見る］［もう一度見る］

■ デザインの決まりごと
- 色は :root の CSS 変数で管理し、ダークモード（prefers-color-scheme）にも対応する
  村陣営 #2f7d5b / 人狼陣営 #c2413a / アクセント #b8862b / 背景 #f4f1ea
- フォントは Zen Kaku Gothic New（Google Fonts）
- 角丸は大きめ（パネル18px、カード14px）、影は薄く
- 幅820px以下では1列にする。参加者は3列のままで、460px以下では2列にする。横スクロールは出さない
- キーボード：スペース＝一時停止/再生、R＝最初から、H＝役職表示の切替

■ データのつなぎ方
- mockup.html の SCRIPT 配列は仮の台本です。実際の対戦ログ（イベント列）を
  同じ形 {step, day, who, text, claim, sys, round, vote, tally, dead, how, win} に変換して流してください
- 役職と伏せ札は観戦用の表示だけに使い、AIプレイヤーに渡すプロンプトには絶対に混ぜないこと
  （いま調査中の game state leakage＝ゲーム状態の漏れ対策と矛盾しないように）

■ 完了条件
- 伏せ札の抽選を1000回回し、人狼が必ず2人配られることと、伏せ札の出方が村人約50%・他の4役職が約12.5%ずつになることをテストで確認する
- 実AIの一試合を最初から決着まで通しで再生でき、コンソールにエラーが出ない
- 役職の表示切替・一時停止・速度変更が動き、決着時に伏せ札が公開される
- 1280×800 と 390×844（ダーク）のスクリーンショットを残す
```
