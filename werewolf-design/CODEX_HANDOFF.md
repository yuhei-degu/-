# Codexへの依頼文（そのまま貼り付けOK）

`mockup.html` を実際のゲーム画面に当てはめるための依頼文です。`mockup.html` を Codex のプロジェクトフォルダに置いてから、下の枠内を貼り付けてください。

---

```
観戦画面の見た目を、同じフォルダにある mockup.html のデザインに合わせて仕上げてください。
ゲームのロジック（情報分離・秘密投票・同票処理・護衛・勝敗判定）と既存テストには手を触れず、表示だけを変えてください。

■ 画面構成（mockup.html と同じ）
1. ヘッダー：タイトル「AI人狼」＋「観戦モード · 6人 · 議論3周」、右に操作ボタン
   ［一時停止/再生］［速度 1×→2×→4×］［役職を表示］［最初から］
2. フェーズの進み具合：夜0·占い → 議論1 → 議論2 → 議論3 → 秘密投票 → 開票 → 決着
   いまのフェーズを塗りつぶしで強調（夜だけ紺色）
3. 左：参加者カード（2列）。アバター（名前の頭文字＋参加者ごとの色）と名前
   - 発言中のカード：枠をその参加者の色にして少し浮かせる
   - バッジ：「占い師CO」「投票済 ✓」「処刑」
   - 役職バッジは「役職を表示」がONのときだけ出す（村陣営は緑、人狼陣営は赤）
   - 処刑されたらグレーにする。開票時は右上に得票数を出す
4. 右：広場（チャット形式）
   - 発言はアバター＋吹き出し。周回の区切りに「議論 2周目」の区切り線
   - 占い結果は色付きのチップ：人狼＝赤「● 人狼」、人間＝緑「○ 人間」
   - システム通知（夜明け・投票開始・処刑）は中央寄せの小さいピル
   - 開票は得票数の横棒グラフと「誰→誰」の一覧
   - 新しい発言が来たら自動で下までスクロール
5. 決着：画面中央に勝敗カード（勝った陣営・周回数・発言数・開票結果・全員の役職公開）
   ［ログを見る］［もう一度見る］

■ デザインの決まりごと
- 色は :root の CSS 変数で管理し、ダークモード（prefers-color-scheme）にも対応する
  村陣営 #2f7d5b / 人狼陣営 #c2413a / アクセント #b8862b / 背景 #f4f1ea
- フォントは Zen Kaku Gothic New（Google Fonts）
- 角丸は大きめ（パネル18px、カード14px）、影は薄く
- 幅820px以下では1列にし、参加者は3列にする。横スクロールは出さない
- キーボード：スペース＝一時停止/再生、R＝最初から、H＝役職表示の切替

■ データのつなぎ方
- mockup.html の SCRIPT 配列は仮の台本です。実際の対戦ログ（イベント列）を
  同じ形 {step, who, text, claim, sys, round, vote, tally, exec, win} に変換して流してください
- 役職は観戦用の表示だけに使い、AIプレイヤーに渡すプロンプトには絶対に混ぜないこと
  （いま調査中の game state leakage＝ゲーム状態の漏れ対策と矛盾しないように）

■ 完了条件
- 実AIの一試合を最初から決着まで通しで再生でき、コンソールにエラーが出ない
- 役職の表示切替・一時停止・速度変更が動く
- 1280×800 と 390×844（ダーク）のスクリーンショットを残す
```
